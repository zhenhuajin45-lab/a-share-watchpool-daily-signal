# 盘前指挥台逻辑规范

## 1. 决策顺序

严格顺序是：**数据新鲜度 -> 大盘情绪 -> 指数结构 -> 作者多空周期 -> SWR 内部合力 -> 外围共振 -> 板块生命周期 -> 仓位上限 -> DeepSeek 反方复核 -> 09:20 状态突变复核**。

后面的模块不能掩盖前面的数据问题。任何单一指标都不能独立放行股票交易。

## 2. 大盘情绪

### 2.1 输入

- 开盘啦综合强度 `K`，0-100。
- 上涨家数 `R`、下跌家数 `F`。
- 涨停数 `LU`、跌停数 `LD`。
- 昨日涨停、连板、炸板样本今日平均表现。
- 当日/预测成交额相对上一交易日变化 `V%`。

### 2.2 分项

```text
breadth_score = R / (R + F) * 100
limit_score   = 50 + (LU - LD) / (LU + LD) * 45
profit_score  = 50 + avg(yesterday_returns) * 15
volume_score  = 50 + V% * 1.5
```

所有分项截断到 0-100。综合情绪：

```text
emotion = 0.35*K + 0.20*breadth + 0.15*limit + 0.20*profit + 0.10*volume
```

### 2.3 状态和基础仓位

| 分数 | 状态 | 基础上限 |
| --- | --- | ---: |
| `<30` | 冰点/防守 | 20% |
| `30-40` | 弱势 | 35% |
| `40-55` | 分化偏弱 | 50% |
| `55-70` | 修复/可选强 | 65% |
| `70-85` | 强势 | 80% |
| `>=85` | 亢奋/防追高 | 90% |

这是第一个上限，不是最终仓位。下跌家数更多、缩量超过 12%、强势股隔日反馈为负时必须输出警告。

## 3. 主要指数

Windows 侧使用 GM SDK 拉取至少 80 根日线，自行计算，禁止依赖屏幕展示值。

- 指数：上证 `SHSE.000001`、深证 `SZSE.399001`、创业板 `SZSE.399006`、科创 50 `SHSE.000688`。
- 指标：收盘、MA5/10/20、5 日/20 日收益、当前量与前 5 日均量比。
- 分类：
  - `close > MA5 > MA10 > MA20`：多头排列。
  - `close >= MA20 且 close >= MA5`：趋势偏强。
  - `close < MA20 且 close < MA5`：趋势偏弱。
  - 其余：震荡分化。
- 两个及以上指数趋势偏弱时，总仓上限压到 35%。

日线只允许使用上一交易日收盘已完成的数据。09:20 竞价差量只能修改当日风险，不能反写历史日线。

## 4. 作者多空比

作者原值是外部独立周期指标：

| 区间 | 解释 | 仓位天花板 |
| --- | --- | ---: |
| `<0.3` | 底部形成观察 | 仍需其它证据 |
| `<0.6` | 负面效应区 | 20% |
| `0.6-1` | 修复但未回归平衡 | 35% |
| `1-1.5` | 多方中位区 | 65% |
| `1.5-2` | 阶段顶部观察区 | 65% |
| `>2` | 趋势突破或拥挤高潮，必须判别 | 65% |

必须同时记录变化方向、连续下降次数和证据来源。`>2` 不是简单看多。公众号断更、正文无数据或 OCR 不清时，不填 0、不沿曲线猜数。

8 月近期已核验样本：8/4=4.54、8/5=6.40、8/11=5.22、8/12=4.20、8/13=2.88、8/14=1.69；8/6、8/7、8/10 为作者断更。

## 5. SWR 内部市场合力

SWR 是策略自有、可复算的内部指标，和作者指标不是同一个公式。

### 5.1 权重与比值

| 分项 | 权重 | 比值计算 |
| --- | ---: | --- |
| 市场广度 | 0.22 | `(上涨+100)/(下跌+100)` |
| 涨跌停结构 | 0.14 | `sqrt((涨停+5)/(跌停+5))` |
| 赚钱效应 | 0.17 | `exp(截断平均收益[-4,4]/3)` |
| 成交量能 | 0.10 | `exp(截断量能变化[-30,30]/25)` |
| 开盘啦强度 | 0.12 | `exp((强度-50)/18)` |
| 指数共振 | 0.13 | `exp(指数平均趋势分*0.70)` |
| 主线周期 | 0.12 | `exp(前12板块排名加权周期分*0.70)` |

有效分项先把比值截断到 `[0.25,4]`，再做加权几何平均。缺失项剔除并重归一，缺失只降低置信度，不作为空方一票。

### 5.2 状态

| SWR | 状态 | 建议区间 |
| --- | --- | --- |
| `<0.60` | 空方占优 | 0-20% |
| `0.60-0.90` | 弱修复 | 20-50% |
| `0.90-1.15` | 多空均衡 | 35-60% |
| `1.15-2.00` | 健康多方 | 35-65% |
| `2.00-4.00` | 高热度/判别突破 | 35-80% |
| `>=4.00` | 极端拥挤 | 20-65% |

作者原值与 SWR 禁止求平均。作者指标给周期位置，SWR 给内部市场验证。

## 6. 外围共振

至少覆盖纳指、标普、费城半导体、英伟达、韩国 KOSPI/KOSDAQ、台湾加权；每条数据带市场时间、前收基准和源质量。

外围只能收紧 A 股科技敏感方向，不能创建买入信号：

- 纳指 `<=-2%`、费城半导体 `<=-3%`、英伟达 `<=-4%`、韩国科技 `<=-3%`、台湾 `<=-3%` 为严重标记。
- 两个严重标记或亚洲熔断证据：量化恐慌。
- 三个严重标记或亚洲熔断证据：深水跌停风险。
- `HIGH` 总仓最多 35%，`EXTREME` 最多 20%。
- 韩国“熔断”必须有交易所/可靠实时源证据，不能由单一涨跌幅标题推断。

## 7. 板块轮动与主攻板块

板块判断不能只看涨跌幅。至少结合：

- 开盘啦当日强度与排名。
- 主力净额及盘中正净流入占比。
- 5/10 日区间排名、涨幅、净额和净流入天数。
- 排名变化、强度变化、盘中节奏。
- 题材资讯与突发利空。

生命周期为：启动、加速、高潮、分歧、退潮。启动/加速可进入主攻候选；高潮只允许重新确认，分歧/退潮禁止新增主攻。

通用指挥分：

```text
0.35*开盘啦验证分 + 排名分 + 生命周期分 + 当日/区间资金分 + 净流入天数分
```

最终仍需具体策略自己的信号和执行门控。本指挥台不输出股票。

## 8. 最终仓位

最终基础上限是下列独立天花板的最小值：

```text
min(情绪上限, 指数上限, 作者周期上限, SWR上限, 外围上限, 数据质量上限)
```

盘中条件扩张最多提高一个 10 点台阶，且必须同时满足：全市场上涨占比不低于 50%、主攻板块上涨占比不低于 60%、量能降幅收窄到 -8% 以上、主攻板块位于 VWAP 上方、外围不高于 MEDIUM。
